# KomaSnap 网页阅读器

把 `dist/` 中的静态文件放到同一个 HTTP 或 HTTPS 站点即可部署。在装有 Node.js 的 Windows 上，双击 `Start-KomaSnap.cmd` 就能打开网页版。也可在项目目录运行 `node serve.mjs`，然后访问 `http://127.0.0.1:4173`。

如需在同一局域网的平板上打开，运行 `node serve.mjs --lan`，然后在平板浏览器中访问终端打印的局域网地址。

- 从设备导入 PDF、无 DRM 的 EPUB、CBZ 或图片 ZIP。书架、书籍文件和阅读位置存在浏览器的 IndexedDB 中。更换浏览器或网址时需要重新导入。
- 点击阅读画面中部或工具栏「进度」调出跳页控件。点击画面两侧、使用方向键或横向拖动即可翻页。
- 图片和 PDF 支持单双页。文字 EPUB 以书内章节为单位，采用内置排版。翻页方式可选左右滑动、仿真卷页和上下滚动。
- 第三方阅读组件及其许可证在 `dist/vendor/`。
